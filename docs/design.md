# PixelProof design

PixelProof fills the trained-model serving gap after webhook reliability, data ingestion and document retrieval projects. Its emphasis is packaging and verifying a trained classifier rather than a novel model: a strict, immutable JSON artifact, bounded inputs, real offline inference, a held-out comparison and inspectable mistakes. No paid service, external inference call, arbitrary file upload, pickle/joblib load, or mocked model. The API uses pure Python math at runtime; NumPy/scikit-learn are training-only extras.

## Fixed experiment

Use the 1,797 samples in scikit-learn `load_digits`, 64 integer pixels (0..16) and labels 0..9. This is a bundled subset of UCI Optical Recognition of Handwritten Digits; attribute its creators and CC BY 4.0 dataset license separately from MIT code. It is a toy low-resolution dataset, not a handwriting product, MNIST, or the official UCI train/test benchmark. The subset does not expose writer IDs, so a random split does not establish writer-independent generalization.

Before measuring, fix stratified `train_test_split(np.arange(n), test_size=0.25, random_state=42, stratify=y)`, then sort each index list. Fit multinomial LogisticRegression(C=1.0, solver='lbfgs', max_iter=1000, tol=1e-4, random_state=42) on training pixels divided by16. No preprocessing learned from test data, hyperparameter search, threshold tuning, or retraining on test. Use a majority-class baseline chosen from training counts (ties lowest digit). Record train/test IDs and their hashes, dataset content hash, configuration, training versions, convergence and held-out errors. No abstention feature; model probabilities are uncalibrated and not guarantees.

Evaluation: held-out accuracy, macro-F1, multiclass log loss, per-digit precision/recall/F1/support, confusion matrix, per-case predicted label/probabilities, all misclassified IDs. Baseline accuracy and macro-F1 (no fake baseline log loss). Report simple fixed stress probes (all-zero, all-16, checkerboard) separately with no accuracy claim or invented labels. The real trained artifact must match sklearn probabilities within 1e-10 across every held-out sample. Capture actual results, including errors; do not promise targets or hide mistakes. CPU timing/throughput not claimed.

## Artifact interface

JSON exact keys: `schema_version` integer1; `feature_count` integer64; `classes` exactly integer0..9; `pixel_max` integer16; `preprocessing` string'divide_by_16'; `coef` list10x64 finite numbers abs<=100; `intercept` list10 finite numbers abs<=100; `training` object (metadata, not executable) with exactly `dataset`, `dataset_sha256`, `train_indices_sha256`, `seed`, `test_fraction`, `estimator`, `C`, `solver`, `max_iter`, `tol`, `sklearn_version`, `numpy_version`. Training fixed values as above; dataset='sklearn.load_digits', estimator='LogisticRegression'; hashes lowercaseSHA256; version strings1..64 printableASCII. Reject bool masquerading as numeric, nonfinite numbers, duplicateJSONkeys, missing/extra fields, invalid dimensions and all other schema deviations. Limit artifact file to256KiB. JSON canonical encoding: sortedkeys, compactseparators, ensure_ascii=True, allow_nan=False, UTF-8. SHA256 of exact artifact bytes is model_id; `.sha256` contains it plus LF. Check supplied expected SHA before accepting artifact, but a checksum is not a signature or proof of trusted provenance.

Primary `Model.from_bytes(data:bytes, expected_sha256:str|None=None) -> Model`; `Model.bundled()` loads `assets/model.json` and `.sha256` through importlib.resources. `predict(pixels:list[int])->dict` validates exactly64 integer0..16(nonbool) and returns `{digit:int, probabilities:list[float]}` in classorder0..9 using stable softmax (subtract maximum logit) and lowest-digit tie break. Immutable tuples internally; exported metadata copies cannot mutate inference. `predict_batch(images:list[list[int]])->list[dict]` validates1..32 images entirely before computing. Pure Python normalizes `/16` then `math.fsum` dot product+intercept; no sklearn import. Blank/full-range inputs are valid but predictions are not treated as meaningful handwritten digits.

## Service and CLI

`create_app(model:Model|None=None)` loads and validates bundled model once before accepting requests; no mutation/reload endpoint. GET /health reports status/model_id; GET /v1/model reports schema/featurecount/classes/preprocessing/training metadata/model_id, never weights. POST /v1/predict accepts exactly `{images:[flat64,...]}`. Content type application/json, strict JSON duplicate/nonfinite rejection. Stream request bytes with a32KiB limit even when Content-Length missing. Errors:415 media type,413 bodylimit,400 invalidJSON,422 validJSONbadschema/pixels. No request-body logging, DB, accounts, or external calls. Predictions include model_id and list `predictions`. Bindloopback default; no auth/rate limits/multi-tenant controls. Demo uses synthetic probes and explicitly attributed public holdout pixels.

CLI: `pixelproof serve [--host127.0.0.1] [--port8000]`; `pixelproof predict PATH.json` reads samebatchpayload capped32KiB and printsJSON; `pixelproof info`. ErrorsJSONstderr exit1, argparseusage2. Local model supplied only via trusted code/API Model.from_bytes (no useruploadedartifactHTTPendpoint). Example input generated from heldoutdata bydemo; no envconfig/secretsnecessary.

## Training worker interface and files

Own training.py, scripts/train.py, tests/test_training.py. `build_bundle()->dict` returns keys `model`(artifactdict), `evaluation`(JSONdict), `split`({train:list[int],test:list[int]}), `test_cases`(list{id:int,pixels:list[int],label:int}). `write_bundle(output:Path)` requires a nonexistentoutputdirectory to prevent overwriting evidence; builds then writes model.json/model.sha256/evaluation.json/split.json/test_cases.json using canonicalmodelbytes (otherJSONindentedLF). Dataset hash is SHA256 of canonical `{'pixels': allintegerrows, 'labels': integerlabels}`; indexhash SHA256 canonical sortedtrainlist. Evaluation includes modelSHA, dataset/indexhashes and config; do not embed localpaths/timestamps. Raise if estimator doesnotconverge. Testpipelineoutputsdisjointpartition/reproducibleIDs, sameclassorder/normalization,baselineusestrainonly, validmetricscounts. Mainwillpublishmodel+sha packagedassets and data/evaluation/split/testcases; heldoutverificationchecks exactsampleIDsagainstbundle and metrics. Re-training may differ at floating-point level across platforms; frozen-model inference and error metrics are verified separately from byte-identical retraining.
