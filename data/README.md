# PixelProof dataset and attribution

PixelProof uses scikit-learn's bundled `load_digits` data for a small, reproducible classifier demonstration. The official documentation describes 1,797 samples with 64 integer features per image, corresponding to 8×8 pixels in the range 0–16. It also identifies `load_digits` as a copy of the test set from the UCI handwritten digits dataset. PixelProof creates its own stratified train/holdout split from this bundled subset; its holdout is not the official UCI train/test benchmark, and the available data does not provide writer IDs for a writer-independent evaluation claim. See the [scikit-learn dataset documentation](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html).

The source dataset is **Optical Recognition of Handwritten Digits** by E. Alpaydin and C. Kaynak (1998), UCI Machine Learning Repository, [DOI 10.24432/C50P49](https://doi.org/10.24432/C50P49). UCI lists the dataset under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The included pixels are attributed to those creators and the UCI repository. PixelProof's changes are the new fixed stratified split, JSON serialization of the selected sample IDs and holdout cases, and a classifier trained on the training partition. The data is a public, low-resolution handwritten-digit collection, not user data.

Dataset attribution and licensing are separate from the repository's MIT code license. The MIT `LICENSE` applies to project code; it does not replace attribution or the CC BY 4.0 terms for source dataset material and derived data artifacts. If you redistribute the pixel data or a derived data artifact, retain the source attribution and license notice and state the changes.

The experiment uses 8×8 integer pixels in the inclusive range 0–16 and digit labels 0–9. Training normalizes pixel values by dividing by 16. The split is stratified with a fixed 25% holdout and seed 42; the design records sorted indexes and hashes so evaluation inputs can be identified. See [split.json](split.json) for the 1,347/450 partition, [test_cases.json](test_cases.json) for held-out pixels and labels, and [evaluation.json](../docs/evaluation.json) for measured results.

This dataset is a toy benchmark for packaging and serving a trained classifier. It is not MNIST, a handwriting product, evidence of generalization to different writers or devices, or a basis for consequential decisions.
